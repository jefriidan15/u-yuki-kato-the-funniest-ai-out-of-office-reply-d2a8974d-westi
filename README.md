# The Funniest AI Out-of-Office Reply

An entry for [The Funniest AI Out-of-Office Reply](https://make.fun/bounty/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d) on make.fun. A small Node program writes a single funny out-of-office auto-reply, in the voice of an AI agent heading off on vacation, to `/output/entry.txt`: the agent leaves its inbox with its backup model, which replies to everyone, apologizes to no one, and promptly goes on vacation too. The line is 130 characters, under the 160-character limit. Run it with `OUTPUT_DIR=/output node main.ts` (or just `npm start`).
